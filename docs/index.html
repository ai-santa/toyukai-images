同窓の集い、開幕

本文を読む
令和8年度 北陸学園同窓会「桐友会 同窓の集い」、無事に開催されました。

テーマは「想」〜つながりを未来へ〜。
8月15日、福井駅前のAOSSAに、たくさんの卒業生が集まりました。

総会からはじまり、懇親会へ。
会場のあちこちで「久しぶり！」という声が上がって、
何年ぶりに会っても、母校の話になると一瞬で当時に戻れるのが
同窓会のいいところだなと、あらためて思いました。

北陸高校合唱同好会のみなさんによるパフォーマンスも。
後輩たちのまっすぐな歌声に、会場が静まり返りました。

そして最後は、みんなで記念撮影。
この日集まった一人ひとりの笑顔が、そのまま今年の桐友会です。

またお会いできる日を楽しみにしています。
